description: 디자인 시안(캡처 이미지)이나 참고 사이트를 보고 사이트 디자인을 바꿉니다
---
사용자가 디자인을 바꾸고 싶어 합니다. 요청 내용: $ARGUMENTS

다음 순서로 진행하세요.

1. 참고 자료 확인
   - 사용자가 이미지를 첨부했거나 `design/references/` 폴더에 이미지가 있으면 먼저 봅니다.
   - 시안에서 읽어낸 것(주요 색 3~5개, 폰트 느낌, 모서리 둥글기, 여백 느낌, 섹션 배치)을 **짧은 표로 먼저 보여주고** 이대로 진행할지 물어보세요.
2. 허락을 받으면 `app/globals.css` 의 `:root` 디자인 토큰부터 바꿉니다.
3. 그다음 필요한 섹션 파일(`components/sections/`)의 배치만 바꿉니다. 글자는 계속 `site.config.ts` 에서 가져오게 유지하세요.
4. 컴포넌트에 색상 코드를 직접 쓰지 말고 토큰 클래스(`bg-primary` 등)를 쓰세요.
5. 끝나면 `npm run build` 로 에러가 없는지 확인하고, 바뀐 파일과 확인 방법을 3줄로 알려주세요.
